📝 Blog Title:
Balancing My MSc in IT and Learning Frontend Development
🚀 Introduction:
Starting my Master’s in IT was exciting, but at the same time, I knew I wanted to build practical skills in frontend development. Managing academics and self-learning web development isn’t always easy, but it has been one of the most rewarding decisions I’ve made. In this blog, I’ll share how I balance both and what I’ve learned so far.
🎓 Why I Chose to Learn Frontend Alongside My MSc
While my MSc program teaches theoretical concepts and core IT subjects, I wanted to build real-world development skills. Frontend development allows me to: Build real projects Improve problem-solving skills Prepare for internships and freelancing Create things I can actually see and use Learning HTML, CSS, JavaScript, and React gives me practical experience that complements my academic studies.
⏰ How I Manage My Time
Balancing both requires discipline and planning. Here’s what works for me: I dedicate 4–5 hours daily to coding. I focus on one main topic at a time (HTML → CSS → JavaScript → React). I avoid watching too many tutorials and focus more on building. I revise concepts on weekends. Consistency is more important than studying for long hours once in a while.
💻 Projects I’m Building
To improve my skills, I’m building projects step by step: Responsive portfolio website Landing page designs JavaScript-based apps like Todo and Weather apps React projects with API integration Each project helps me understand real development challenges like responsiveness, debugging, and clean code structure.
🧠 Challenges I Face
Balancing academics and coding isn’t always smooth. Some challenges include: Academic deadlines Feeling overwhelmed by new technologies Comparing myself to others Debugging frustration But I remind myself that progress takes time. Small improvements every day matter.
🌱 What I’ve Learned So Far
Consistency beats motivation. Building projects is better than just watching tutorials. Deploying projects builds confidence. Mistakes are part of learning. Frontend development is not just about writing code — it’s about solving problems creatively.
🎯 My Goal
Over the next few months, my goal is to: Build strong React projects Create a professional portfolio Land a remote internship Start freelancing This journey is just beginning, and I’m excited to see how far I can go.
💬 Final Thoughts
If you're also balancing studies and skill development, remember: You don’t need to be perfect. You just need to stay consistent. Every small project, every line of code, and every challenge is shaping your future.
